# Desktop modes

What the SeeBand desktop application passes to its calculations, per model and fit mode. Model descriptions in C8 are generated from this data.

The data is in [`desktop_modes.json`](../src/seeband_core/data/desktop_modes.json). Values read from the code cite their source line there, except `display_scale`, which is the inverse of the line-edit scale. Meanings are our description. All links point to SeeBand commit `803b0e7`. The energies below are in kelvin.

## How to read the scales

Desktop sliders hold integers, so each parameter has scales that convert the slider value:

- **Display:** the value shown to the user.
- **Fit:** the start value passed to the fit.
- **Calc:** the value passed to the curve calculation when a slider moves. Other paths can differ, as each mode shows.

When these scales differ for one parameter, the desktop treats that slider inconsistently. See the deviations below.

For acPhDis, the core also multiplies some parameters by 300, because they are given at 300 K. This applies to both start values and bounds, and results are divided on return, except in the case recorded as D6.

## Bounds

**Fit bounds** are the values at startup. Bounds marked _editable_ are live slider ranges that Advanced options can change. Qt then clamps the current slider value, so changing a range can also change a start value, including the fixed SPB mass. Other bounds are fixed constants.

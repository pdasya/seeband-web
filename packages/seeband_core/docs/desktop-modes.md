# Desktop modes

What the SeeBand desktop application passes to its calculations, per model and fit mode. Model descriptions in C8 are generated from this data.

The data is in [`desktop_modes.json`](../src/seeband_core/data/desktop_modes.json), and every value there cites its source line. All links point to SeeBand commit `803b0e7`. The energies below are in kelvin.

## How to read the scales

Desktop sliders hold integers, so each parameter has scales that convert the slider value:

- **Display:** the value shown to the user.
- **Fit:** the start value passed to the fit.
- **Calc:** the value passed to the curve calculation.

When the three scales differ for one parameter, the desktop treats that slider inconsistently. See the deviations below.

The default fit range is 50 to 800 K, shared between all windows ([`seeband.py:40`](https://github.com/xAngelswordx/SeeBand/blob/803b0e7a425a0a3f4f59688df77e3ad283ca49a1/seeband.py#L40), [`seeband.py:41`](https://github.com/xAngelswordx/SeeBand/blob/803b0e7a425a0a3f4f59688df77e3ad283ca49a1/seeband.py#L41)). Curves have 50 points.

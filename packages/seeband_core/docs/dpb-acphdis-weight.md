# Pointwise DPB acPhDis Seebeck (P11)

Total Seebeck uses the band weight at each temperature. Previously the
loop overwrote the weight array with its last scalar, so all temperatures
used the last point's weight. The fit objective, plotted curve and RMSE
could therefore disagree simply because they evaluated different grids.

## Equation and units

With the existing conductivity integrals σ₁, σ₂ and Onsager integrals O₁,
O₂, the calculation is

```text
q(T) = B (C_K + T) / ((D_K + T) r)
S(T) = scale (O₁(T) + q(T) O₂(T)) / (σ₁(T) + q(T) σ₂(T)).
```

Here r is the internal mass coordinate, not the public R used by the S-only
conversion. C_K and D_K are kelvin temperature scales: public dimensionless
C and D are multiplied by 300 K exactly once at the existing boundary.
Mass/degeneracy conventions, the scattering law, and all fit weights, bounds
and stopping thresholds are unchanged. The per-band implementation already
used q(T) pointwise; P11 removes only the scalar reassignment in total S.

For r = 1, gap = 300 K, E_F = −100 K, N = B = 1, public C = 0.5 and D = 2
(C_K = 150 K, D_K = 600 K), q(300 K) = 0.5 and q(800 K) = 0.678571429.
Before P11, S(300 K) on the two-point grid was 63.523744 µV/K, against
94.381907 µV/K on its own. After the correction both give 94.381907 µV/K.
These values were run on the P8 solver base; the low-level C/D numbers are
not dimensionless ratios.

## Regression evidence

Tests cover ascending, descending, shuffled, subset and duplicate grids,
singletons, scaling, nonunit degeneracy and an explicit pointwise formula.
They verify that weighted band contributions sum to total S in both mixed
modes, C = D reduces to constant-weight scattering, and B = 0 removes the
second band's transport contribution. Negative-r cases test algebraic
consistency only: the signed transport-weight issue (#104) is still open.
Physical positive-weight checks do not validate that negative-weight model.

P8 supplies independent checked chemical potentials. Without it, the old
warm-start solver could still make a result depend on temperature order even
after fixing q(T). RMSE still uses a finite interpolation grid; P11 removes
the artificial weighting dependence, not ordinary interpolation error.
A test changes another quantity's temperature extent while keeping the S
measurement exactly at a common grid endpoint, excluding interpolation as
an explanation of any change in S RMSE.

The original desktop captures and `p8.json` are unchanged.
`tests/fixtures/physics/p11.json` records 24 affected mixed-scattering calls,
including all six fits, and pins the P8 fixture hash. It is generated by the
implementation and is regression evidence, not independent physics proof.
All unaffected historical calls retain their P8 expectations. Regenerate:

```sh

```

The four converged fits took three iterations both before and after. B, C
and D remain at their existing bounds near 1.1, 2 and 0.5. Hall-mode m₁

The two 02 fits still fail chemical-potential verification; P11 does not
replace those failures with numbers. Convergence, active bounds and parameter
movement do not prove model validity, parameter identifiability or a global
optimum. Existing iterative degeneracy, negative-weight, collapsed-band and
Fermi-integral limitations remain separate, as does the broader final-stage
fit consistency issue (#176).

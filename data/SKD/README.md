# SKD measurement samples

Source: user-supplied `ZEM_data.xlsx`. All samples are retained irrespective of fit quality.

Each sample has a separate directory. Load `*_see.txt` as Seebeck (V/K) and `*_rho.txt` as resistivity (Ohm*m).
`*_source.csv` preserves source units, values, temperature grids and worksheet row numbers.
Carrier concentration and mobility are supplementary source data; no Hall coefficient has been inferred.

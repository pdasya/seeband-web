# PbTe Lorenz evidence for review

This package preserves the distinct PbTe studies, including unsuccessful source reproductions. Start with the latest [source and implementation audit](formula-audit/REVIEW.md), then [replay instructions](REPLAY.md). These are offline research calculations, not a production three-band feature or a physical validation of every SeeBand model. No numerical model was changed for this collection.

The Thesberg Figure 6 curves and Pei supplementary Figure S3(b) fractions are published **calculations**. The measured Hall and resistivity readings used later are separate constraints. Digitized curve precision is not experimental uncertainty. Earlier notes describe the evidence available at their stage; the latest source-only inversion and edge-bound checks give stronger constraints than the earlier suggestion of a possible legend reversal. The underlying cause remains unresolved.

## Provenance and curation

Original study collection: `analysis/PbTe-Thesberg-Fig6` in the SeeBand research workspace. The recorded source hashes, path indices, axis anchors, raw vertices, reading bounds and exact core revisions are retained. They describe historical audit evidence; new checks performed for this collection are recorded in [VALIDATION.md](VALIDATION.md).

Browse the [Fig. 6 comparison](comparison.png), [chemical potential and conductivity fractions](ref49/mu-and-conductivity.png), and [Kane replay](kane/comparison.png) alongside the derived tables and scripts. Full papers, supplements, patent PDFs, publisher HTML, source page images/crops, ZIP bundles and bytecode are omitted. Source links and extraction settings are in the study notes and replay instructions. Plots can be regenerated. Brief numerical digitizations are derived evidence rather than author-supplied datasets.

Exact duplicates were consolidated: baseline scripts/tables live here; 700 K budget lives in `order700/`; Fig. 5 slices and extraction script live in `formula-audit/`; Pei fractions live in `ref49/inset/`; the rho reading lives in `mobility400/resistivity/`. Readers use relative paths to those canonical copies. Distinct historical `record.json` files remain because their provenance/conclusions differ. Changes to copied computational scripts are input-path changes only; formulas, constants, solvers and outputs are preserved.

Review still needs source-owner clarification of the original trajectories, valley/prefactor conventions and inconsistent source constraints. Agent audit does not replace human physicist confirmation.

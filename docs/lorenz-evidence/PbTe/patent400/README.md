# PbTe patent reconstruction and SeeBand checks

Run python compare.py (SciPy, NumPy) to regenerate comparison.csv. Mobilities in cm²/(V s), electrical resistivity in mΩ cm. Table rows use prospective fixed concentrations, no fitted weights. ../mobility400/resistivity/rho400.csv is the Nature Fig. 3a reading for Na-doped PbTe, reproduced in the patent.

US9059364B2: https://patentimages.storage.googleapis.com/62/cc/dc/5258554c629281/US9059364.pdf pages 15–17. For xSe=0 the Kane gap is 0.34 eV and L sits 0.02 eV above Sigma at 400 K. Effective masses at 300 K (C,L,Sigma) are 0.3,0.36,2 in electron masses; C and L scale as sqrt(T/300). Patent masses are single-band equivalent with no extra valley factor in density. Spin is included once. For the patent rows the calculation fixes total holes and evaluates each family with explicit degeneracy one. It uses a scalar mass in both mobility factors or, as a sensitivity study, an ellipsoidally averaged inertia using K_L=K_C=3.58. The patent gives the Hall anisotropy factor but no unique conductivity-mass or acoustic-prefactor prescription. Mobilities use Eq. 3 of https://arxiv.org/pdf/1111.5355 after division by the Hall factor. For comparison both versions use v_l=3600 m/s, ideal PbTe density 8249 kg/m³ (C_l=106.9 GPa), adopted from the previous Nature study. A common elastic modulus cancels in b, while rho scales inversely with it. The Nature row uses grouped DOS for density and single-valley masses for mobility, resolving 4/12/4 valleys (L/Sigma/C), with fixed net holes. The patent's generic L=8 and Sigma=12 description is not an additional multiplicity applied to its equivalent masses. See https://authors.library.caltech.edu/records/r4cjr-qn161/files/nature09996-s1.pdf#page=3 and https://www.nature.com/articles/nature09996/figures/3 .

For the actual core comparison run check_spb.py with packages/seeband_core/src from pdasya/seeband-web revision 9929fb4ffb04a93fcca2bfbce28548c58c61ad35 on PYTHONPATH plus dependencies installed. spb.csv includes 69 equally spaced reduced chemical potentials from -5 to 12. Kim et al. https://doi.org/10.1063/1.4908244 is an approximate L(S) at acoustic SPB; 3.652% maximum deviation normalized to the core value. Kim & Kim https://doi.org/10.3365/KJMM.2021.59.2.127 Table 1 gives ionized-impurity S; maximum absolute difference from independently integrated formula 1.024e-9 µV/K. These two checks cover selected SPB core observables. The patent reconstruction is offline research.
